Synapse · Task 4

Deep Learning

A self-paced course on the Task 4 notebook set — the neuron, backprop by hand, Keras, CNNs, RNNs, GANs, attention.

Mission Deep mastery of the Task 4 deep-learning toolkit for exams and future ML work, applied through the two notebooks. See MISSION.md.

18 lessons in 6 phases, foundations first. Each lesson: intuition → math → code → mistakes → recap → exercises → quiz.

Phase 0 · Foundations — one neuron, and how it learns

  • 01. The artificial neuron & the perceptron Why deep learning, node / weight / bias / activation, and learning OR.
  • 02. Learning rules & activation functions Hebbian vs delta rules; step, bipolar, sigmoid; input-range gotchas.
  • 03. The XOR wall One line can't split XOR — the reason hidden layers exist.

Phase 1 · From one neuron to a real network (from scratch)

  • 04. Backprop: one neuron learns addition Forward pass, loss, gradients, the update; why big inputs explode to nan.
  • 05. A full network from scratch (MNIST) Shapes, sigmoid, softmax, cross-entropy, one-hot; the magic dL/dZ₃ = A₃ − target.
  • 06. Debugging training Zero init, learning rate too big / too small, reading a loss curve.

Phase 2 · Deep learning in the real world (Keras / TensorFlow)

  • 07. Keras building blocks (adult income) Sequential, Dense, Input, compile / fit / evaluate / predict.
  • 08. Judging a model honestly Accuracy vs class imbalance, the "always predict ≤50K" baseline, precision & recall.
  • 09. Tensors & automatic differentiation What a tensor is, the computational graph, and why not just NumPy.
  • 10. What hidden layers learn Feature learning, the Playground spiral demo, curved boundaries.

Phase 3 · Seeing — Convolutional Neural Networks

  • 11. Convolution & the CNN Filters, feature maps, pooling, weight sharing; why CNN ≫ ANN for images.
  • 12. Training a CNN & overfitting CIFAR-10, the train-vs-val gap, dropout / augmentation / early stopping.
  • 13. Transfer learning Pretrained MobileNetV2, frozen base, new head, fine-tuning, tiny learning rate.

Phase 4 · Memory — Recurrent Neural Networks

  • 14. RNNs from scratch & BPTT Hidden state, weights shared across time, and the backward pass.
  • 15. RNNs in Keras (IMDB sentiment) Embedding, SimpleRNN, padding, vocab size, max_len.
  • 16. Why RNNs fail — LSTM & GRU Vanishing / exploding gradients over long sequences; the gated fix.

Phase 5 · Generation & the frontier

  • 17. Generative adversarial networks Generator vs discriminator, adversarial training, the toy 1-D GAN.
  • 18. Transformers & attention Self-attention, Q / K / V, scaled dot-product, why √d_k. Research/reading.
