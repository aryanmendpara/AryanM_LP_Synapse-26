Backprop: one neuron learns addition

The one skill: do one forward + backward pass by hand for a single neuron.

By the end you can Compute prediction ŷ = w1*x1 + w2*x2 + b, MSE loss, derivatives dL/dw, dL/db, update with gradient descent, and explain why large inputs/weights can produce NaN.

Goal

Learn to add two numbers with a single neuron: no activation (linear) is natural here because we want the sum (unbounded). Start from random weights/bias, show the network the examples, correct it via gradient descent.

Forward pass

z = w1*x1 + w2*x2 + b  (or np.dot(x, w) + b)
ŷ = z  (identity/linear)

Loss: Mean Squared Error

L = (1/2)(y - ŷ)^2  (1/2 makes derivative clean)
or L = (y - ŷ)^2 / n

Backprop (chain rule)

We want ∂L/∂w, ∂L/∂b. Note ŷ = z.

∂L/∂ŷ = -(y - ŷ)
∂ŷ/∂z = 1
∂z/∂w1 = x1, ∂z/∂w2 = x2, ∂z/∂b = 1

∂L/∂w1 = ∂L/∂ŷ * ∂ŷ/∂z * ∂z/∂w1 = -(y - ŷ) * x1
∂L/∂b  = -(y - ŷ)

Gradient descent updates: w ← w - η * ∂L/∂w, b ← b - η * ∂L/∂b. With ∂L/∂w = -(y-ŷ)x this becomes w ← w + η (y-ŷ)x — same form as the perceptron/delta rule but derived for MSE + linear output.

Connection The delta rule is the gradient descent update for MSE on a linear unit.

Worked micro-example

Example: x=[2,3], y=5, init w=[0.1,0.2], b=0, η=0.01

  1. z = 0.1*2 + 0.2*3 + 0 = 0.2 + 0.6 = 0.8, ŷ=0.8
  2. error = y-ŷ = 4.2, L=(1/2)(4.2)^2 large
  3. ∂L/∂w1 = -(4.2)*2 = -8.4 → w1 ← 0.1 - 0.01*(-8.4)=0.1+0.084=0.184
  4. ∂L/∂w2 = -(4.2)*3 = -12.6 → w2 ← 0.2+0.126=0.326
  5. ∂L/∂b = -(4.2) → b ← 0+0.042=0.042
  6. Next pass gives better ŷ; repeat until close.

Ideally weights converge toward ~[1,1], bias toward ~0.

Why NaN on big numbers?

Two common causes:

  • Large inputs: If x,big, initial weights random can produce huge z/ŷ; squared error explodes. Gradients -(y-ŷ)x become huge → weights/bias blow up → overflow to inf → NaN.
  • Large learning rate: Overshoots badly, causes divergence.

Fixes: Normalize/scale inputs (e.g., divide by max), use smaller learning rate, or standardize. The model doesn't need huge values if inputs are scaled.

Implementation sketch (Task_4A style)

import numpy as np

class Add2NumsModel:
    def __init__(self, num_inputs, lr):
        self.w = np.random.randn(num_inputs)*0.01
        self.b = np.random.randn(1)*0.01
        self.lr = lr
    def predict(self, x):
        return np.dot(x, self.w) + self.b  # linear
    def train(self, X,y,epochs):
        for ep in range(epochs):
            preds = np.dot(X,self.w)+self.b
            err = y - preds  # shape (n,)
            dW = -np.mean(err[:,None]*X, axis=0)  # MSE derivative form varies
            # easier: use (y-ŷ) form: w += lr*(y-ŷ)*x
            self.w += self.lr * np.dot(X.T, err)/len(X)
            self.b += self.lr * np.mean(err)
            if ep%100==0: print('mse', np.mean(err**2))

Note: be careful about shapes and sign conventions. The key is understanding the chain rule.

Recap

  • Linear neuron + MSE gives delta rule form.
  • Backprop = chain rule down to weights/bias.
  • Scale inputs to avoid gradient explosion/NaN.
  • Weights converge to coefficients that approximate the function.
