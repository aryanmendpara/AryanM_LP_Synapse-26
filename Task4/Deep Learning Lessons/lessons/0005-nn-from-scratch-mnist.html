Lesson 05 · Deep Learning

A full network from scratch (MNIST)

The one skill: trace a 2-layer network (input→hidden→output) for one MNIST image.

By the end you can Explain shapes, sigmoid activation, softmax for multiclass, cross-entropy, one-hot encoding, and the key simplification dL/dZ₃ = A₃ - y.

Architecture (typical)

  • Input: 784 (28x28 flattened)
  • Hidden: e.g. 128 neurons, sigmoid
  • Output: 10 neurons (digits 0-9), softmax

Shapes

W1: (hidden, input), b1: (hidden,1)
Z1 = W1·X + b1, A1 = σ(Z1)
W2: (output, hidden), b2: (output,1)
Z2 = W2·A1 + b2, A2 = softmax(Z2)  # predictions

Activations

  • Sigmoid: σ(z)=1/(1+e^{-z}), range (0,1). Smooth gradient.
  • Softmax: softmax(z_i)=e^{z_i}/∑_j e^{z_j}, outputs sum to 1 — treat as probabilities over classes.

Loss: Cross-entropy (multiclass)

For one example, L = -∑_c y_c log(A2_c). With one-hot y (1 at true class), this is -log(p_{true}).

Backprop key result

For softmax + cross-entropy, the gradient of loss w.r.t. pre-activation of output layer simplifies beautifully:

dZ2 = A2 - y  (shape same as A2/y)

That's the "magic" — no big product of derivatives, just prediction minus true label (one-hot). From there use chain rule to get dW2, db2, dZ1, dW1, db1.

Gradients (sketch)

dZ2 = A2 - y
dW2 = dZ2 * A1^T / m
db2 = sum(dZ2)/m
dZ1 = (W2^T * dZ2) * σ'(Z1)  (elementwise)
dW1 = dZ1 * X^T / m
db1 = sum(dZ1)/m

Update: W -= lr*dW.

Training loop (structure)

  1. Load MNIST, normalize to [0,1], one-hot encode labels
  2. Init W1,b1,W2,b2 small random
  3. For epochs: for each batch/example do forward → compute loss → backward → update
  4. Track accuracy on train/test
Important Vectorize with NumPy (matrix multiply) — don't loop over neurons/inputs manually if you can avoid it.

Common gotchas

  • Shapes: X is (784, m), W1 (128,784) gives (128,m). Get shapes right.
  • Softmax overflow: Subtract max before exp (as notebook mentions).
  • Zero init: Bad for symmetry in deeper nets (Lesson 6).
  • Learning rate: Too big oscillates/diverges, too small slow.
