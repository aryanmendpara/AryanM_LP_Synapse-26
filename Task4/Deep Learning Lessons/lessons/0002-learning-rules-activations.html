Lesson 02 · Deep Learning

Learning rules & activation functions

The one skill: tell Hebbian from the delta rule, and pick the right activation for a task.

By the end you can Distinguish Hebbian learning (Δw = η x y) from the perceptron/delta rule (Δw = η (y − ŷ) x), list the step/bipolar/sigmoid activations and their ranges, and explain why nonlinearity matters.

Two ways a neuron learns

Not all "learning rules" are the same. The key difference is what signal drives the update.

1) Hebbian learning ("cells that fire together, wire together")

Donald Hebb's idea: if an input neuron and an output neuron fire at the same time, strengthen the connection between them. No teacher label is required — it's unsupervised correlation-based learning.

Δw_i = η · x_i · y    # strengthen when both active
w ← w + Δw
  • Drives on correlation: if both x_i and y are +1, weights grow. If one is -1 and other +1, they oppose and weights shrink.
  • No error term: there's no "y_true − ŷ". Hebbian learns what co-occurs, not "what's correct".
  • Watch out for growth: without normalization/decay, weights can grow without bound (a common gotcha).

2) Delta rule / Perceptron learning rule ("learn from mistakes")

The rule from Lesson 1 is the delta rule for a linear/perceptron unit: use a supervisor (a label y) and update only when there's an error.

error = y − ŷ
Δw_i = η · error · x_i
Δb   = η · error
w ← w + Δw,  b ← b + Δb
  • Drives on error: correct predictions give error=0 → no update (self-stabilizing).
  • Supervised: needs y (true label).
  • Goal: reduce the difference between prediction and label.
Rule of thumb Hebbian = "fire together, wire together" (correlation). Delta/perceptron = "wrong? fix it." (error correction).

Activation functions: the "gate" of the neuron

The activation decides what the neuron outputs after z = w·x + b. Different activations change the range of outputs and (critically later) the gradient.

FunctionFormula (intuition)Output rangeWhere usedNotes
Step (binary)f(z)=1 if z≥0 else 0{0,1}Perceptron (Lesson 1)Sharp threshold; no gradient (can't do gradient descent).
Bipolar stepf(z)=+1 if z≥0 else -1{-1,+1}Some older nets / bipolar perceptronsSymmetric around 0; sometimes nicer with bipolar inputs.
Sigmoid (logistic)σ(z)=1/(1+e^{-z})(0,1)Binary classification output (single neuron); historical hidden layersSmooth, S-shaped. Outputs can be interpreted as probability. Squashes large |z| to near 0 or 1 (vanishing gradient in deep nets).

Why range matters

  • Outputs vs logic: If you need a strict yes/no (the original perceptron), step/bipolar is direct. If you need a probability for binary classification, sigmoid is natural.
  • Input compatibility: Bipolar activations pair well with bipolar inputs {-1,+1} (they're symmetric). Binary {0,1} is also common and matches the perceptron examples.
  • Nonlinearity is the superpower: A single linear neuron gives a straight line. Stacking linear layers without a nonlinear activation still gives only a straight line. Add a nonlinear activation (like sigmoid) between layers and you can form curves — which is how a small network learns XOR (Lesson 3).
Key point No activation (or identity) = linear. Nonlinear activation = can bend boundaries.

Quick sanity checks

QuestionCheck
Is Hebbian supervised?No. It uses correlation x·y, not y_true − ŷ.
When does delta rule update?Only on error. If prediction matches label, error=0 → no change.
Can a perceptron use gradient descent?Not directly. The step function has zero gradient almost everywhere (and undefined at 0), so we use the perceptron rule (error correction), not smooth gradient descent on step.
Why sigmoid for output?It maps any real number to (0,1), easy to interpret as P(y=1|x) for binary classification.

Recap — five bullets

  • Hebbian: Δw = η x y — correlation-based, unsupervised; "fire together, wire together".
  • Delta/perceptron: Δw = η (y − ŷ) x — error-correcting, supervised; only updates on mistakes.
  • Step: {0,1}, threshold at 0. Good for hard decisions, bad for gradients.
  • Bipolar step: {-1,+1}, symmetric. Pairs naturally with bipolar inputs.
  • Sigmoid: (0,1), smooth and probabilistic. Nonlinear — essential to stack layers beyond a straight line.

Answer key

  1. B — correlation between input and output, no error term.
  2. A — updates on y − ŷ != 0.
  3. C — sigmoid gives (0,1), interpretable as probability.
  4. A — step has zero/undefined gradient; use error-correcting rule instead.
  5. A — W₂ (W₁ x + b₁) + b₂ = (W₂ W₁) x + (W₂ b₁ + b₂) is linear.
  6. B — {-1,+1}.
  7. Hebbian: w_i ← w_i + η · x_i · y. Delta/perceptron: w_i ← w_i + η · (y − ŷ) · x_i (supervised by error).
  8. Without nonlinearity, stacked layers collapse to one linear function (only straight boundaries). A nonlinear activation bends the feature space so hidden units can create combinations that form a nonlinear boundary capable of separating XOR.
  9. Sigmoid. Step gives a hard 0/1 but no gradient for training; sigmoid gives a smooth (0,1) output (probabilistic) and works well as a binary classifier output (and pairs with cross-entropy).
  10. Normalize or apply decay/weight normalization (e.g. keep weights bounded, or use Oja's rule which adds a decay term) so correlation doesn't cause unbounded growth.
