Transfer learning

The one skill: reuse a pretrained model wisely.

By the end you can Explain feature extraction vs fine-tuning, freezing layers, and when to use them.

Idea

Take a model trained on large dataset (ImageNet) and adapt to your task. Leverages learned features.

Approaches

  • Feature extraction: Freeze base model, add new classifier head, train only head (fast, small data)
  • Fine-tuning: Unfreeze some top layers of base + train head with very small learning rate (more data/similar domain)

Example (MobileNetV2)

base = tf.keras.applications.MobileNetV2(input_shape=(224,224,3), include_top=False, weights='imagenet')
base.trainable = False  # freeze
model = Sequential([base, GlobalAveragePooling2D(), Dense(128,activation='relu'), Dense(num_classes,activation='softmax')])
