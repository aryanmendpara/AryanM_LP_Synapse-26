Convolution & the CNN

The one skill: explain why CNNs beat ANNs for images.

By the end you can Describe filters/kernels, feature maps, convolution, pooling, weight sharing, and local connectivity.

Why not flatten to Dense?

Flattening a 32x32x3 image gives ~3072 inputs; a first Dense layer explodes in parameters. Also loses spatial structure (nearby pixels matter).

Convolution

Slide a small kernel (filter) over the image, compute dot product → produces a feature map. Kernel learns to detect edges/textures.

Key ideas

  • Local connectivity: Each neuron looks at small receptive field
  • Weight sharing: Same kernel used across image → fewer params
  • Translation equivariance: Detects features anywhere

Pooling

Reduce spatial size (max/average pooling) → fewer params, more robust to small shifts.

Typical CNN

Conv2D(filters, kernel_size) -> ReLU -> MaxPooling2D
-> Conv2D -> ReLU -> MaxPooling2D
-> Flatten -> Dense -> Dense(softmax)
