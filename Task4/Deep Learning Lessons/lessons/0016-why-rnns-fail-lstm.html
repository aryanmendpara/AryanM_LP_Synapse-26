Why RNNs fail — LSTM & GRU

The one skill: explain gates and long-term memory.

By the end you can Explain vanishing/exploding gradients, LSTM cell state/gates, and why they help.

The problem

Long sequences → repeated multiplication by W_hh causes gradients to vanish/explode. SimpleRNN forgets long-range dependencies.

LSTM idea

Add a cell state (conveyor belt) that carries information across long time with minimal modification. Gates control flow:

  • Forget gate: what to remove from cell state
  • Input gate: what new info to store
  • Output gate: what to output based on cell state

GRU (simplified)

Combines forget/input into update gate, merges cell/hidden state. Fewer params, often similar performance.

When to use

  • Long sequences → use LSTM/GRU
  • Short sequences → SimpleRNN might suffice
