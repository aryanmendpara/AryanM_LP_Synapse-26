Judging a model honestly

The one skill: beat a dumb baseline and look past accuracy.

By the end you can Compute/check a majority-class baseline, read confusion matrix, precision/recall, and spot class imbalance traps.

The trap of accuracy

If 90% of people earn ≤50K, a model that always predicts ≤50K gets 90% accuracy but learns nothing. Always compare to a baseline (majority class, random).

Confusion matrix (binary)

Predicted +Predicted -
Actual +TPFN
Actual -FPTN
Accuracy = (TP+TN)/(TP+TN+FP+FN)
Precision = TP/(TP+FP)  # of predicted positives, how many correct?
Recall = TP/(TP+FN)     # of actual positives, how many found?

When to care

  • High precision: minimize false positives (spam filter - don't want to block legit mail)
  • High recall: minimize false negatives (disease detection - don't want to miss sick patients)
