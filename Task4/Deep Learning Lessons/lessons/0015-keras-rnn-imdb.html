RNNs in Keras (IMDB sentiment)

The one skill: build an RNN for text classification.

By the end you can Explain embedding, padding/truncation, vocab size, max_len, and SimpleRNN/LSTM basics.

Pipeline

  1. Tokenize text → sequences of word indices
  2. Pad/truncate to fixed max_len
  3. Embedding(vocab_size, embedding_dim) maps words to dense vectors
  4. SimpleRNN/LSTM processes sequence
  5. Dense(1, activation='sigmoid') for sentiment

Example

from tensorflow.keras.datasets import imdb
from tensorflow.keras.preprocessing.sequence import pad_sequences
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Embedding, SimpleRNN, Dense

(x_train,y_train),(x_test,y_test)=imdb.load_data(num_words=10000)
x_train = pad_sequences(x_train, maxlen=500)
x_test = pad_sequences(x_test, maxlen=500)

model = Sequential([
  Embedding(10000, 32),
  SimpleRNN(32),
  Dense(1, activation='sigmoid')
])
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
model.fit(x_train,y_train, epochs=5, batch_size=64, validation_split=0.2)

Key terms

  • Embedding: Learns word representations (dense) vs one-hot
  • Padding: Make all sequences same length
  • Truncation: Cut long sequences
