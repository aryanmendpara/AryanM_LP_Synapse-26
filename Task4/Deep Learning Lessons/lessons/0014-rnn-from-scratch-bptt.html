RNNs from scratch & BPTT

The one skill: understand hidden state and backprop through time.

By the end you can Explain recurrence, shared weights, hidden state, and the idea of BPTT.

Why RNNs?

Sequential data (text, time series) where order matters. RNNs have memory via hidden state carried across time steps.

Equations (simple RNN)

h_t = tanh(W_hh * h_{t-1} + W_xh * x_t + b_h)
y_t = W_hy * h_t + b_y

Weights W_hh, W_xh, W_hy are shared across all time steps.

Backpropagation Through Time (BPTT)

Unroll the RNN over time steps (like a deep network) and backpropagate errors backwards through time steps, summing gradients for shared weights.

Vanishing/exploding gradients

Multiplying by same weights repeatedly over long sequences causes gradients to shrink to 0 (vanish) or blow up (explode) — hard to learn long-range dependencies.
