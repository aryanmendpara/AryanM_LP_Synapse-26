Unsupervised Learning — the Map

One page to orient every algorithm in the Task 3 set. Print it, keep it beside the notebook.

Unsupervised learning has no target variable. Every task here is some way of finding structure in X alone. Three families cover the whole Task 3 set:

Clustering — pick by cluster shape

AlgorithmIdeaNeeds k?Good forFails when
K-MeansPartition: assign each point to the nearest of k centroids, then move centroids; repeat.YesRound, compact, similar-sized blobs.Non-spherical shapes, outliers, unequal sizes.
Agglomerative (hierarchical)Bottom-up: each point starts alone; repeatedly merge the two closest clusters. Output = dendrogram.Cut later (or set k)When you don't know k; nested structure.Big data (O(n²)); one wrong merge is permanent.
DBSCANDensity: grow clusters from dense core points; sparse points become noise.NoArbitrary shapes, and finding outliers (label −1).Density varies a lot; high dimensions.
SpectralGraph: connect similar points, cut the graph into pieces with few weak edges.YesRings, moons, connectivity-shaped clusters.Large n (eigen-decomposition); badly-built graph.

K-Means and Agglomerative are both distance-based and give every point a cluster. DBSCAN and Spectral are the two that break the "round blob" assumption — Spectral via connectivity, DBSCAN via density.

Dimensionality reduction — PCA

PCA rotates the feature space onto new orthogonal axes (principal components) ordered by how much variance they capture. Keep the first few, drop the rest. Use it to visualise high-dimensional data in 2D/3D and to speed up clustering. Always standardize first.

Association rules — market-basket style

Find "if A then B" patterns: {bread, butter} → {milk}. Measured by support (how often A∪B appears), confidence (how often B is present given A), and lift (how much more often than chance; >1 = useful). Apriori prunes using the property "if an itemset is rare, all its supersets are rare"; FP-Growth is the faster tree-based alternative.

Evaluation — how to know a clustering is good

  • Silhouette (−1…1): how much closer a point is to its own cluster than the next. Higher is better.
  • Davies–Bouldin (≥0): average similarity of each cluster to its most-similar neighbour. Lower is better.
  • Inertia / WCSS: sum of squared distances to centroids — the thing K-Means minimises and the elbow method plots.
