DBSCAN — density-based clustering

The one skill: tune eps and min_samples, and read the noise label.

By the end you can Explain core / border / noise points, choose eps and min_samples, fit DBSCAN and count outliers, and say when to prefer it over K-Means. Fills your notebook's two DBSCAN cells.

The idea — follow the density

K-Means and hierarchical clustering ask "which centroid/tree is closest?". DBSCAN asks "is this region dense?". It grows clusters from dense seeds and leaves sparse points as noise — so it finds clusters of any shape and gives you an outlier detector for free.

Three kinds of point

Two parameters: eps (neighbourhood radius) and min_samples (how many neighbours count as dense).

TypeDefinition
CoreHas at least min_samples points within radius eps (including itself).
BorderWithin eps of a core point, but not itself core.
NoiseNeither of the above → labelled −1.

Algorithm: pick an unvisited core point, start a cluster, repeatedly absorb every point density-reachable from it; when no core points remain in reach, start the next cluster from another unvisited core point.

The one-sentence version. DBSCAN forms clusters by chaining together points that are densely packed, and marks everything too sparse to belong as noise.

Fitting it — the core code

from sklearn.cluster import DBSCAN
import numpy as np

db = DBSCAN(eps=0.5, min_samples=5)   # the two knobs
labels = db.fit_predict(data_pca)     # one label per row; noise = -1

n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
n_noise    = np.sum(labels == -1)
print("clusters:", n_clusters, "| noise:", n_noise)

Syntax note: there is no predict() for new points — fit_predict() does both (DBSCAN isn't a reusable model). The core points are exposed as db.core_sample_indices_.

Choosing the parameters

  • Scale first. eps is an absolute distance, so unscaled features wreck it — standardize (as you already did).
  • min_samples: rule of thumb ≈ 2 × n_features, larger for noisier data.
  • eps: read it off a k-distance plot (code below).
from sklearn.neighbors import NearestNeighbors

k = 5                                  # set k = your min_samples
nbrs = NearestNeighbors(n_neighbors=k).fit(data_pca)
distances, _ = nbrs.kneighbors(data_pca)   # (n, k)
k_dist = np.sort(distances[:, k - 1])      # each point's k-th neighbour distance

plt.plot(k_dist)                       # the "knee" of this curve ≈ a good eps
plt.xlabel('Points (sorted)'); plt.ylabel(f'{k}-th neighbour distance')
plt.title('k-distance plot'); plt.show()

The notebook's 2D cell — completed

from ipywidgets import interact
import matplotlib.pyplot as plt

def dbscan_clustering(eps, min_samples):
    dbscan = DBSCAN(eps=eps, min_samples=min_samples)
    dbscan_labels = dbscan.fit_predict(data_pca)

    plt.figure(figsize=(8, 6))
    plt.scatter(data_pca[:, 0], data_pca[:, 1],
                c=dbscan_labels, cmap='viridis', edgecolors='k', alpha=0.7)
    plt.xlabel('Principal Component 1')
    plt.ylabel('Principal Component 2')
    plt.title(f'DBSCAN (eps={eps}, min_samples={min_samples})')
    plt.show()

interact(dbscan_clustering, eps=(0.1, 2.0, 0.1), min_samples=(2, 20, 1))

The notebook's 3D cell — completed

def dbscan_3d_clustering(eps, min_samples):
    dbscan = DBSCAN(eps=eps, min_samples=min_samples)
    labels_3d = dbscan.fit_predict(data_pca)

    fig = plt.figure(figsize=(10, 8))
    ax = fig.add_subplot(111, projection='3d')
    ax.scatter(data_pca[:, 0], data_pca[:, 1], data_pca[:, 2],
               c=labels_3d, cmap='viridis', edgecolors='k')
    ax.set_xlabel('Principal Component 1')
    ax.set_ylabel('Principal Component 2')
    ax.set_zlabel('Principal Component 3')
    ax.set_title(f'DBSCAN 3D (eps={eps}, min_samples={min_samples})')
    plt.show()

interact(dbscan_3d_clustering, eps=(0.1, 2.0, 0.1), min_samples=(2, 20, 1))

The only differences from the K-Means cells: DBSCAN takes eps/min_samples instead of n_clusters, and the −1 noise points show as their own colour.

When it struggles. Clusters of very different densities (one eps can't fit all), and high-dimensional data where "density" stops being meaningful. It also can't label every point — noise is intentional.
