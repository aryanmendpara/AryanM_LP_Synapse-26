DBSCAN — density-based clustering

The one skill: tune eps and min_samples, and read the noise label.

By the end you can Explain core / border / noise points, choose eps and min_samples, fit DBSCAN and count outliers, and say when to prefer it over K-Means. Fills your notebook's two DBSCAN cells.

The idea — follow the density

K-Means and hierarchical clustering ask "which centroid/tree is closest?". DBSCAN asks "is this region dense?". It grows clusters from dense seeds and leaves sparse points as noise — so it finds clusters of any shape and gives you an outlier detector for free.

Three kinds of point

Two parameters: eps (neighbourhood radius) and min_samples (how many neighbours count as dense).

TypeDefinition
CoreHas at least min_samples points within radius eps (including itself).
BorderWithin eps of a core point, but not itself core.
NoiseNeither of the above → labelled −1.

Algorithm: pick an unvisited core point, start a cluster, repeatedly absorb every point density-reachable from it; when no core points remain in reach, start the next cluster from another unvisited core point.

The one-sentence version. DBSCAN forms clusters by chaining together points that are densely packed, and marks everything too sparse to belong as noise.

Fitting it

from sklearn.cluster import DBSCAN
import numpy as np

db = DBSCAN(eps=0.5, min_samples=5)
labels = db.fit_predict(data_pca)

print("clusters:", len(set(labels)) - (1 if -1 in labels else 0))
print("noise points:", np.sum(labels == -1))   # the −1 label

Choosing the parameters

  • Scale first. eps is an absolute distance, so unscaled features wreck it — standardize (as you already did).
  • min_samples: rule of thumb ≈ 2 × n_features, larger for noisier data.
  • eps: use a k-distance plot — sort each point's distance to its min_samples-th nearest neighbour and look for the "knee"; set eps there.
When it struggles. Clusters of very different densities (one eps can't fit all), and high-dimensional data where "density" stops being meaningful. It also can't label every point — noise is intentional.
