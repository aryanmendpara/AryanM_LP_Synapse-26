Spectral clustering

The one skill: explain why a graph-view clustering beats K-Means on rings and moons.

By the end you can Walk the five steps (graph → matrices → Laplacian → eigenvectors → K-Means), explain the eigengap, run it in scikit-learn, and state spectral vs K-Means. This is Part 2 of your research doc.

The idea — cluster by connectivity, not distance

K-Means assumes round, compact clusters. Two concentric rings defeat it — each ring's centroid sits in the middle, so K-Means cuts across both. Spectral clustering treats the data as a graph: points are nodes, similar points get edges. A good clustering cuts the graph into pieces that few, weak edges cross.

The one-sentence version. Spectral clustering builds a similarity graph and cuts it so clusters stay internally well-connected, which lets it follow curved, non-round shapes that K-Means can't.

The five steps

  1. Build a similarity graph — typically a k-NN graph or an RBF (Gaussian) kernel exp(−γ‖x−y‖²).
  2. Form matrices — W the affinity (similarity) matrix; D the degree matrix (diagonal, row sums of W).
  3. Graph Laplacian — L = D − W, or the normalized L_sym = I − D^(−1/2) W D^(−1/2).
  4. Eigenvectors — take the k eigenvectors of L with the smallest eigenvalues; each point becomes a row in a new n × k space.
  5. Cluster — run K-Means on those rows.

Why it works

  • The graph-cut view is what we want but is NP-hard to solve exactly; the small eigenvectors of the Laplacian are a smooth, tractable approximation of the best cut.
  • If the graph has k disconnected pieces, the Laplacian has exactly k eigenvalues equal to 0, and those eigenvectors point straight at the pieces.
  • Choosing k: find the eigengap — a big jump between consecutive sorted eigenvalues; k is the count before the jump.
  • Hidden dimensionality reduction: step 4 re-embeds the data so tangled, curved clusters become compact and easy for K-Means to separate.

Python

from sklearn.datasets import make_circles
from sklearn.cluster import SpectralClustering, KMeans

X, _ = make_circles(n_samples=500, factor=0.3, noise=0.05, random_state=42)

sc = SpectralClustering(n_clusters=2, affinity='nearest_neighbors',
                        n_neighbors=10, random_state=42)
sc_labels = sc.fit_predict(X)     # separates the two rings

km_labels = KMeans(n_clusters=2, random_state=42).fit_predict(X)
# K-Means cuts each ring in half; spectral keeps the rings whole

Spectral vs K-Means (your doc's table)

K-MeansSpectral
Cluster shapeRound, compact blobsArbitrary — rings, moons, connectivity
BasisDistance to a centroidGraph connectivity / similarity
SpeedFastSlow: eigen-decomposition of an n×n matrix
Choosing kElbow / silhouetteEigengap (either needs k)
Sensitive toInitial centroids, outliersHow the similarity graph is built

Uses: image segmentation, community detection, document grouping, gene-expression clustering. Weakness: doesn't scale to very large data.
