Evaluating clusters & K-Means vs Agglomerative

The one skill: justify a clustering without labels, using silhouette and friends.

By the end you can Explain the silhouette score, name two other metrics and their direction, use silhouette to choose k, and write the K-Means vs Agglomerative comparison. Fills notebook cells on silhouette and the reflection prompt.

The problem: there are no labels

In supervised learning you score against the truth. Here there is none, so we use internal metrics that reward two things:

  • Cohesion — points in a cluster are close to each other.
  • Separation — different clusters are far apart.

Silhouette score — the main one

For each point:

  • a = mean distance to the other points in its own cluster (cohesion).
  • b = mean distance to the points of the nearest other cluster (separation).
  • s = (b − a) / max(a, b)  →  ranges −1 to +1.

Average s over all points. Higher is better: near +1 means points sit comfortably inside their cluster; near 0 means they're on a boundary; negative means they're probably in the wrong cluster.

from sklearn.metrics import silhouette_score

score = silhouette_score(data_pca, labels)   # labels from any clustering

# use it to choose k:
for k in range(2, 8):
    labels = KMeans(n_clusters=k, random_state=42).fit_predict(data_pca)
    print(k, round(silhouette_score(data_pca, labels), 3))

Two more metrics (know the direction)

MetricMeasuresRangeBetter when…Call
SilhouetteCloseness to own cluster vs the nearest other−1 … 1highersilhouette_score
Davies–BouldinAverage cluster similarity to its closest neighbour≥ 0lowerdavies_bouldin_score
Calinski–HarabaszBetween-cluster to within-cluster dispersion ratio≥ 0highercalinski_harabasz_score

Davies–Bouldin compares each cluster's spread to how far it sits from its most-similar cluster — small spread, big gaps = low score = good. Calinski–Harabasz is a variance ratio (between-cluster ÷ within-cluster, like an F-statistic) — big gaps, tight clusters = high score = good. Both are relative: only compare them across the same dataset.

The exam trap. Davies–Bouldin is the odd one out — lower is better. It measures the average similarity between each cluster and its most-similar neighbour.

K-Means vs Agglomerative (your reflection cell)

K-MeansAgglomerative
TypePartitional (centroids)Hierarchical (merges)
kMust supply up frontChosen after, from the dendrogram

Similarities: both are distance-based, both assign every point to exactly one cluster (no noise label), and both generally prefer compact, well-separated groups — which is why they can agree on clean blob-like data and disagree on ring/moon shapes.
