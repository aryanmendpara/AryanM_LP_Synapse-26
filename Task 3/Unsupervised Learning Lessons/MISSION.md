# Mission: Unsupervised Learning (the Task 3 set)

## Why
Venus is working through the Synapse **Task 3** ML assignment and wants to go past filling in blanks: to genuinely *master* the unsupervised-learning toolkit (PCA, K-Means, Hierarchical, DBSCAN, Association Rules, Spectral Clustering) so it holds up in exams and future ML work — while finishing the notebook and research doc correctly along the way.

## Success looks like
- Explain each algorithm's intuition, when to reach for it, and how it fails — from memory, without notes.
- Write the `scikit-learn` / `mlxtend` / `scipy` code for each from a blank cell.
- Choose hyperparameters (`k`, `eps`, `min_samples`, `n_components`, `linkage`, support/confidence) and justify the choice.
- Evaluate clusters (silhouette, Davies–Bouldin) and read association-rule metrics (support / confidence / lift).
- Complete Task 3's notebook answers and the research doc with confidence.

## Constraints
- Breadth is scoped to the **Task 3 algorithm set**; **depth** is the priority.
- Sessions are short — lessons must be quick to complete and quick to review later.

## Out of scope (for now)
- Supervised learning (covered in Tasks 1–2).
- Deep-learning representation learning (autoencoders, embeddings) — maybe later.
